# 限次复审模式

在访谈已经收敛后，对锁定结果做独立、只读、有限轮次的逆向检查。复审不重新开启全部问题，只攻击可能改变决定的薄弱点。

## 启用条件

用户明确要求复审，或决定同时具备高成本、难逆转和重大风险。普通问题跳过复审。

## 执行

1. 形成一份锁定结果，至少包含目标、关键决定、依据、约束、风险、未决项和下一步。
2. 若环境提供独立审阅者或第二模型，让其只读材料并寻找致命假设、遗漏选项、证据断裂、边界冲突和更简单方案。不得要求其实施。
3. 若没有独立审阅者，使用新的审查视角自行复核，并明确说明这是同模型复核。
4. 审阅者对每个问题给出影响、依据和最小修正，最后只给出 `通过`、`修改` 或 `阻塞`。
5. 主代理判断意见是否成立：采纳的修改写回锁定结果；拒绝的意见记录理由。
6. 默认最多 2 轮。两轮后仍有实质分歧时列出分歧，由用户裁决，不制造通过结论。

## 路由审查重点

- **工程**：安全、权限、数据迁移、并发、失败恢复、兼容性、测试与可观察性。
- **科研**：研究问题与证据是否匹配、替代解释、测量与识别、可行性、可复现性和贡献夸大。
- **决策**：价值排序、机会成本、不可逆性、基础概率、二阶后果和退出条件。
- **思辨**：概念偷换、证据等级、隐藏前提、最强反方和过度心理推断。

复审结束后仍由用户作最终决定。
